# Advay Tripathi Coding Projects

A responsive personal website showcasing coding projects from `advay4ever`.

Featured repos:

- `Delphic-AI`: Math and Science tutor built while learning Python, Flask, AI APIs, SymPy, SQLite, and pytest.
- RecallQ (`memory-match-mobile`): TypeScript audio memory game, presented with
  the RecallQ name and logo in this portfolio. Gameplay previews retain the
  original Memory Match branding.

## Open locally

Open `index.html` in your browser.

## Customize

- Add an email address and LinkedIn URL if you want visitors to contact you that way.
- Project screenshots live in `assets/delphic-ai-screenshot.png` and
  `assets/memory-match-showcase.png`. Each preview opens the full-size image.
- Keep project descriptions and the Python skill breakdown in `index.html`
  aligned with the work in each repository.
- The RecallQ logo is stored at `assets/recallq-logo.png`.
- Swap `assets/hero-workspace.png` if you want a different hero image.
